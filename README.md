# Entheogen Atlas — Sacred Plants, Science & the Law

A complete research atlas of entheogenic substances: archaeology, neuroscience, legal history, phenomenology, and religious use — mapped across 60,000 years.

**Live:** https://entheogen-atlas.vercel.app

## Repository contents

`api`, `evidence-register.json`, `governance.html`, `index.html`, `robots.txt`, `sitemap.xml`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
